# Modernization workspace

This directory starts empty except for this contract. Agents create evidence and decisions here as a modernization progresses; do not pre-populate it with example results.

Expected generated structure:

```text
modernization/
  inventory/          Extraction manifests and reconciliation
  analysis/           System context, dependencies, rules, data, interfaces, and risks
  architecture/       Target decisions, ADRs, contracts, threat model, and data mappings
  plans/              MVP roadmap, bounded slice plans, traceability, rollout, and rollback
  evidence/           Characterization, parity, accessibility, security, performance, and operations results
```

These artifacts are lifecycle checkpoints and agent handoffs. They remain versioned with the implementation because they record why code exists and what evidence supports it. They are generated by the Legacy Analyst, Modernization Planner, and Validation Critic, not stored in another service automatically.

Do not put target application code, credentials, production records, or unmasked protected data here.
